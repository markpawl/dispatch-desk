# Dispatch Desk

A text editor that acts like a desktop: type freely, then dispatch selected text to configured
destinations (email, a project file, a document, a data store, an AI-routed location, and so on) —
see `docs/PLATFORM-OVERVIEW.md` for the concept as currently understood.

## Repository layout

- `docs/` — requirements, architecture, and planning docs. See the individual files for what's
  decided vs. still open.

No code yet — this repo currently holds only the docs scaffold.
